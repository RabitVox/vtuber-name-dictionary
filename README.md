# VTuber Name Dictionary
VTuberの名前をまとめた辞書データです。

## 協力 (Contributing)
名前の追加・修正などの提案を受け付けています。

### Google Form

Pull RequestやIssueの作成が難しい場合は、Googleフォームから情報を送信できます。

- [VTuber名の追加・修正を提案する](https://forms.gle/3voEkiczqzm9fwrVA)

### Issue

GitHub Issueからも追加・修正を提案できます。

以下の情報を記載してください。

- VTuber名
- 読み
- 修正内容
- 情報の出典（可能であれば）
